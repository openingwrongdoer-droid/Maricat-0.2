## Settings
Change the window scale to any number and then save.
## How to use
Finally.
In the bin foldet there's the makefile to compile the app.
In the release folder you'll find the precompiled app for 64 bit x86 Windows. 
The cpp code uses Windows functions so it actually only works in that enviroment for now.
Put your project in the the folder and double click on MariCat.exe.
